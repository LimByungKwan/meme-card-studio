[과제 3 제출용]

결과물 URL:
https://사용자명.github.io/저장소명/

소스 저장소 URL:
https://github.com/사용자명/저장소명

짧은 확인 방법 4줄
1. 위치: 위 결과물 URL을 새 시크릿 창에서 열고 첫 화면의 이미지·문구 편집 도구와 미리보기를 확인합니다.
2. 행동: PNG/JPEG 이미지를 불러온 뒤 문구 위치·크기·색 또는 1:1·4:5·9:16 비율을 바꾸고 PNG로 저장합니다.
3. 통과 모습: 변경 내용이 즉시 미리보기에 반영되고 내려받은 파일의 이미지 잘림·문구 위치·줄바꿈이 같은 모습으로 열리며, 저장한 템플릿은 새로고침 뒤에도 유지됩니다.
4. 안 될 때 모습: 지원하지 않는 파일이나 손상·필수 누락 JSON은 이유가 표시되고 기존 이미지·편집 내용·템플릿 목록은 사라지지 않습니다.

AI와 나의 판단 3줄
1. AI에게 맡긴 일: HTML/CSS/JavaScript 구조, Canvas 렌더링, 템플릿 CRUD, JSON 검증, 테스트 초안을 만드는 데 AI의 도움을 받았습니다.
2. 직접 판단한 일: 과제 통과 기준에 맞춰 사용할 이미지·문구, 최종 화면비와 테스트 입력을 확인하고 실제 브라우저 동작과 공개 제출 주소를 직접 검토했습니다.
3. AI 제안을 따르지 않은 일: 과제 요구와 다른 16:9 비율 제안은 사용하지 않고 안내에 명시된 1:1·4:5·9:16만 적용했습니다.
