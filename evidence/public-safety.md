# 공개 안전 확인

## 위치 정보 메타데이터

- 업로드된 원본 파일을 그대로 배포하지 않습니다.
- 브라우저가 원본 이미지를 픽셀로 디코딩한 뒤 Canvas에서 새 PNG/JPEG Blob을 생성합니다.
- 원본 EXIF/GPS 메타데이터를 새 파일에 복사하는 로직이 없습니다.
- `output/` 샘플 3개는 프로젝트에서 코드로 직접 생성한 그래픽이며 EXIF/GPS 메타데이터가 없습니다.

## 개인정보

공개 화면, README, evidence 파일, 샘플 이미지에 이름·주소·전화번호·이메일·학번 등 개인 식별 정보를 넣지 않았습니다.

## 비밀값

이 프로젝트는 외부 API를 사용하지 않습니다. API key, access token, password, `.env` 파일이 필요하지 않으며 저장소에도 포함하지 않습니다.

## 공개 전 마지막 수동 확인

GitHub에 올리기 전 저장소 전체 검색으로 다음 문자열이 없는지 확인합니다.

- `API_KEY`
- `SECRET`
- `TOKEN`
- `PASSWORD`
- 개인 전화번호/이메일/주소
